Elágazás

if

Logikai feltételek:

Egyenlő: a == b
Nem egyenlő: a != b
Kevesebb, mint: a < b
Kevesebb vagy egyenlő, mint: a <= b
Nagyobb, mint: a > b
Nagyobb vagy egyenlő, mint: a >= b

elif

Az elif kulcsszó a Python azon értelmű megfogalmazása, hogy „ha az előző feltételek nem voltak igazak, akkor próbáld ki ezt a feltételt”.
Például:
a = 33
b = 33
if a > b:
print("Az a nagyobb, mint a b.")
elif a == b:
print("Az a és a b megegyezik.")

else

Az else kulcsszó mindent elkap, amit az előző feltételek nem kapnak el.
Például:
a = 200
b = 33
if b > a:
print("A b nagyobb, mint az a.")
elif a == b:
print(Az a és a b megyezik.)
else:
print("Az a nagyobb, mint b")
